# Сдвиг

«Сдвиг» — музыкальный веб-инструмент для исполнения короткого космического джазового этюда. В нём взаимодействуют два голоса: саксофон с певучей мелодией и барабаны с мягким ритмом. Исполнитель меняет их баланс, характер и пространственную обработку во время воспроизведения.

Проект разрабатывается для первого модуля курса по интерактивному дизайну. Текущая версия — работающий прототип для предпросмотра.

## Концепция

Инструмент предлагает управлять музыкальным пространством через небольшое число понятных действий: оставить один голос, подключить второй, изменить тембр, развести звук по панораме, добавить эхо и реверберацию. Название «Сдвиг» связывает изменения звучания с ощущением движения в пространстве.

Визуальная основа — тёмное космическое окружение, золотые орбитальные потоки и полупрозрачная панель управления. Саксофон и барабаны представлены отдельными карточками с одинаковой логикой управления. Световые акценты показывают текущий шаг музыкальной фразы, а движение звёзд и пыли создаёт ощущение медленного полёта.

## Музыкальный эскиз

Основа композиции — восьмитактовая мелодическая тема с вариацией, паузами и мягким завершением. Начальный темп — 88 BPM, размер — 4/4. Партии записаны на сетке из восьми шагов на такт; весь цикл содержит 64 шага.

Саксофон воспроизводит локальные семплы, а барабаны синтезируются средствами Tone.js. Подписи Dm9, Bbmaj7, Fmaj7 и Cadd9 обозначают гармонические ориентиры мелодии: отдельного голоса с аккордовым сопровождением в прототипе нет.

Музыкальная последовательность подготовлена с помощью ИИ по выбранному автором направлению. Представленные музыкальные референсы использовались для обсуждения настроения и характера звучания; их аудиозаписи не включены в проект.

## Возможности прототипа

- Общие запуск, остановка, темп и громкость.
- Независимые громкость, панорама и отключение каждого голоса.
- Фильтр низких частот, эхо и регулятор реверберации «Пространство» у обоих голосов.
- Режимы саксофона «Мягко», «Воздушно» и «Коротко», меняющие атаку и затухание звука.
- Режимы барабанов «Щётки» и «Палочки», меняющие характер малого барабана.
- Подсветка шагов, указатель такта и индикатор выходного уровня.
- Адаптивная компоновка и космический фон с возможностью остановить анимацию.

Регуляторы работают до запуска и во время исполнения. После остановки следующий запуск начинает музыкальную фразу заново. Режимы инструментов меняют звучание; переключение ритмических рисунков и редактирование нот в интерфейсе пока не реализованы.

## Запуск

Требуется Node.js 20.19–20.x либо 22.12 и новее и npm.

```sh
npm ci
npm run dev
```

Откройте адрес из терминала и нажмите «Играть». Звук запускается после действия пользователя. Для проверки собранной версии:

```sh
npm run build
npm run preview
```

Сборка находится в `dist`. Семплы саксофона хранятся внутри проекта. Шрифт Manrope загружается из Google Fonts; при его недоступности используется системный шрифт.

## Устройство инструмента

Интерфейс написан на HTML, CSS и JavaScript. Звук создаётся через Tone.js 15.1.22 и Web Audio API, фон — через Canvas 2D. Vite используется для локального запуска и сборки. React в текущей версии не используется.

У каждого голоса своя цепочка обработки:

```text
Саксофон / барабаны → фильтр → реверберация → эхо → канал голоса
Каналы голосов → плавное включение и выключение → общая громкость → лимитер → выход
```

Каналы имеют независимые громкость и панораму. Индикатор измеряет сигнал после лимитера. Обе партии синхронизированы общим транспортом Tone.js; последовательности воспроизводятся через `Tone.Sequence`.

| Файл | Назначение |
| --- | --- |
| `index.html` | Каркас страницы, общее управление и область голосов |
| `src/patterns.js` | Ноты, ритм, гармонические ориентиры и начальные настройки |
| `src/instruments.js` | Семплер саксофона и синтез барабанов |
| `src/audio.js` | Класс `SynthEngine`: аудиограф, эффекты, каналы и воспроизведение |
| `src/main.js` | Создание панелей голосов и связь элементов управления со звуком |
| `src/space.js` | Класс `SpaceScene`: движение звёзд и золотой пыли |
| `src/style.css` | Визуальное оформление, состояния элементов и адаптивность |

В интерфейсе повторяются панели голоса, регуляторы, переключатели режимов и кнопки отключения. Панели создаёт функция `createVoicePanel`, а набор регуляторов описан общим массивом настроек. Идентификаторы связывают голос с параметром: например, `saxophone-reverb` и `drums-volume`. CSS-классы обозначают назначение элемента (`voice`, `control`, `pattern`) или его состояние (`is-active`, `is-muted`).

Анимация ограничена 30 кадрами в секунду и приостанавливается в скрытой вкладке. После остановки освобождаются аудиоузлы и приостанавливается аудиоконтекст. Индикатор уровня обновляется только во время воспроизведения в видимой вкладке.

### Промпт-дизайн

Ниже приведены обобщённые формулировки по истории работы. Они передают задачи, ограничения и последовательность уточнений, но не являются дословной стенограммой запросов.

**1. Анализ задачи и ограничение объёма**

> По представленным требованиям и учебным материалам предложи поэтапный план создания музыкального веб-инструмента. Сначала выдели минимальный объём для первого модуля: два голоса, отдельные каналы, цепочки эффектов и понятный интерфейс. Учти возможность дальнейшего развития, сохранив небольшой объём текущего прототипа.

Результат: разделение данных партий, звукового движка и интерфейса; определение базового набора функций.

**2. Первый прототип по референсам**

> Проанализируй представленные референсы веб-инструментов и выдели полезные принципы их устройства. Разработай самостоятельный прототип на JavaScript и Tone.js с двумя синхронизированными партиями, общим запуском и независимыми настройками голосов. Используй понятные названия и оставляй только краткие пояснения к крупным функциям и классам.

Результат: первоначальная реализация воспроизведения, каналов, эффектов и элементов управления; дальнейшие изменения внесены в ходе совместной работы.

**3. Визуальная концепция**

> По представленным визуальным референсам предложи оформление музыкального инструмента в образе космического джаза. Используй тёмное пространство, тёплые золотые акценты, полупрозрачную центральную панель и отдельные карточки двух голосов. Сохрани читаемость подписей и понятные состояния элементов управления.

Результат: выбранное визуальное направление, компоновка интерфейса и его дальнейшая реализация в HTML и CSS.

**4. Генерация фонового изображения**

> Создай оригинальный горизонтальный космический фон для музыкального веб-инструмента. Палитра — почти чёрный и тёмно-синий с мягким золотым свечением. Размести фрагменты планет по краям, а изогнутые потоки золотой пыли — преимущественно внизу. Центральную область оставь тёмной и свободной для панели управления. На изображении должны быть только элементы космоса, без текста и интерфейса.

Результат: растровый фон `public/images/cosmic-jazz.png`. Изображение используется как часть оформления; движение звёзд и пыли создаётся отдельно на Canvas.

**5. Звучание и музыкальная тема**

> Развивай прототип как дуэт саксофона и барабанов. По представленным музыкальным референсам предложи самостоятельную спокойную тему с певучей фразировкой, паузами и мягким ритмом. Используй вариацию внутри короткой циклической формы. Подбери темп, длительности нот и обработку так, чтобы оба голоса можно было различить и балансировать во время игры.

Результат: восьмитактовая тема, ритмическая партия и настройки артикуляции. Запрос уточнялся после оценки звучания первой версии.

**6. Регуляторы и уточнение интерфейса**

> Добавь независимую регулировку реверберации для каждого голоса и назови её «Пространство». Значения должны отображаться рядом с регулятором и меняться во время исполнения. Уточни отступы элементов, прозрачность панели и расположение стрелок выпадающих списков, сохранив общий стиль.

Результат: управление реверберацией и уточнения оформления элементов интерфейса.

**7. Производительность и движение фона**

> Проверь, освобождаются ли ресурсы после остановки и повторного запуска, не накапливаются ли обработчики и отложенные события. Сократи ненужные обновления в скрытой вкладке. Добавь ощущение непрерывного медленного полёта вперёд по изогнутой траектории с постоянным числом частиц и возможностью остановить анимацию.

Результат: исправления жизненного цикла звука и визуальных обновлений, ограничение частоты отрисовки и перспективное движение частиц.

### Оценка эффективности и ограничения

ИИ помог получить работающий прототип, связать управление со звуком и последовательно уточнить оформление и музыкальный эскиз. Результаты потребовали нескольких итераций: первая мелодия была изменена после обратной связи, а анимация и работа звукового движка — после проверки нагрузки.

В ходе разработки проверялись сборка, изменение параметров, остановка и повторный запуск. Проверка памяти включала 12 циклов запуска и остановки и двухминутное воспроизведение; в этом прогоне не обнаружен устойчивый рост памяти JavaScript. Такая проверка не гарантирует одинаковое поведение на всех устройствах и при длительной работе.

Описание музыкальных референсов не заменяет их прослушивание и авторскую оценку. При подготовке музыкального эскиза ИИ не подтвердил непосредственное прослушивание записей по внешним ссылкам.
